# مناسبة (Manasiba)

تطبيق إدارة المناسبات والدعوات باللغة العربية.

## الميزات

- إنشاء وإدارة المناسبات (زفاف، خطوبة، ميلاد، تخرج...)
- إضافة وإدارة المدعوين
- استيراد جهات الاتصال
- بطاقات دعوة قابلة للتخصيص (5 قوالب، ألوان، خطوط)
- عد تنازلي حي للمناسبات
- مشاركة الدعوات وحفظها كصورة
- إحصائيات المدعوين

## المتطلبات

- Flutter SDK >= 3.0.0
- Dart SDK >= 3.0.0

## التشغيل

```bash
flutter pub get
flutter run
```

## البناء

### Android
```bash
flutter build apk --release
flutter build appbundle --release
```

### iOS
```bash
flutter build ios --release
```
